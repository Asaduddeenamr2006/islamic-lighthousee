# islamic-lighthouse

Quran reading web application with dark mode support.

## Getting Started

1. Clone the repository:
```bash
git clone <repository-url>
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
```

## Deploy

This project can be deployed on [Vercel](https://vercel.com) or any hosting platform that supports Next.js.
