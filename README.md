# 🕌 Islamic Lighthouse - Quran Dark

تطبيق ويب للقرآن الكريم بتصميم داكن أنيق، مبني بـ Next.js 16.

## ✨ الميزات

- 📖 قراءة القرآن الكريم بتصميم داكن مريح للعين
- 🎧 الاستماع لتلاوات من 12 قارئ مختلف
- 📱 وضع التركيز على القراءة (للهواتف فقط)
- 👆 التمرير باللمس بين الصفحات (للهواتف فقط)
- 🔍 البحث في السور
- 🎨 تخصيص الألوان وحجم الخط
- 📚 تفسير الآيات من 8 مصادر مختلفة
- 🌐 دعم كامل للغة العربية (RTL)

## 🚀 التثبيت والتشغيل

```bash
# تثبيت الاعتمادات
npm install

# تشغيل وضع التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل نسخة الإنتاج
npm run start
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## 🛠 التقنيات المستخدمة

- **Next.js 16** - إطار عمل React
- **TypeScript** - كتابة آمنة
- **TailwindCSS 4** - التصميم
- **Firebase Hosting** - الاستضافة

## 📱 الميزات الخاصة بالهاتف

### التمرير باللمس
- مرر لليسار → الصفحة التالية
- مرر لليمين → الصفحة السابقة
- مرر لليمين في أول صفحة → آخر صفحة من السورة السابقة
- مرر لليسار في آخر صفحة → أول صفحة من السورة التالية

### وضع التركيز
اضغط على أيقونة العين 👁 في الشريط العلوي لإخفاء جميع العناصر والتركيز على نص القرآن فقط.

## 🌐 النشر
